Fruit Drop

Drop cute fruit in the jar — two alike merge into a bigger one!

▶ Play Fruit Drop now Get the app on Google Play

How to play Fruit Drop

  1. Drag to move the claw, release to drop the fruit. The bubble shows what comes next.
  2. Two identical fruits that touch merge into the next one: cherry, strawberry, grape, orange… all the way to a Golden Melon. Quick chains build combos.
  3. If fruit stays above the red line for two seconds, the jar overflows and the run ends.
  4. Swap and Pop helpers save tight spots; later Rainbow Drops, Bombs, Shrink Potions, golden fruit and Frenzy bonuses appear. Upgrades widen the jar and add swaps.

Missions to chase

Every run counts toward missions that pay out XP. Clear a tier to unlock the next one:

  • Grow an Apple
  • Merge 100 fruits in total
  • Score 1,500 in one run
  • Grow a Pineapple
  • Hit a 6x merge combo
  • Use 20 specials or helpers

Upgrades

Coins you earn buy permanent upgrades for Fruit Drop:

  • 🫙 Big Jar — +7% jar width for more room
  • 🔄 Juggler — +1 Swap helper at the start of a run
  • 🪙 Market Day — +15% coins from each run

Good to know

  • Free and instant: runs in your browser on phone, tablet or desktop — nothing to install.
  • Session length: about 3–10 min per round, perfect for a short break.
  • Progress saves automatically in this browser: best scores, missions and favorites.
