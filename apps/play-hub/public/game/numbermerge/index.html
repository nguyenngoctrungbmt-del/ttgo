Number Merge

Place number blocks — equal neighbours merge and grow.

▶ Play Number Merge now All games

How to play Number Merge

  1. Tap an empty cell to place the current block. The small block on the right comes next.
  2. Connected equal blocks merge into the one you placed and double for every extra block — merges can chain.
  3. Make the goal tile to clear the level — fewer placements earn more stars. Dark cells are blocked; a full board with no merge ends the run.
  4. Stones crack when merges happen next to them. Rainbow jokers copy the best neighbour, bombs blast a 3×3. Hammer, Swap and Undo help — upgrades add more.

Missions to chase

Every run counts toward missions that pay out XP. Clear a tier to unlock the next one:

  • Make a 128 tile
  • Merge 200 times in total
  • Cascade a 3-step chain
  • Make a 512 tile
  • Reach level 5
  • Merge 3,000 times in total

Upgrades

Coins you earn buy permanent upgrades for Number Merge:

  • 🔨 Hammer Kit — +1 Hammer at the start of a run
  • 🔄 Quick Swap — +1 Swap at the start of a run
  • 🪙 Number Cruncher — +15% coins from each run

Good to know

  • Free and instant: runs in your browser on phone, tablet or desktop — nothing to install.
  • Session length: about 3–10 min per round, perfect for a short break.
  • Progress saves automatically in this browser: best scores, missions and favorites.
