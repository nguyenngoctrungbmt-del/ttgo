Block Jam

Slide colour blocks out through their matching doors.

▶ Play Block Jam now Get the app on Google Play

How to play Block Jam

  1. Drag a block to slide it around the board — it stops when it hits another block, a rock or the wall.
  2. Push a block into a wall door of the same colour (and symbol). If the door is wide enough, the block slides out.
  3. Clear every block before the timer runs out. Two-colour blocks peel at the outer door, striped blocks move one way only, frozen blocks thaw as others leave, locks open when the key block exits.
  4. Hammer smashes a block, Vacuum pulls out a whole colour, Freeze stops the clock. Upgrades add time, hammers and coins.

Missions to chase

Every run counts toward missions that pay out XP. Clear a tier to unlock the next one:

  • Reach level 3
  • Clear 40 blocks
  • Get 3 stars on 2 levels in a run
  • Reach level 8
  • Clear 400 blocks
  • Beat 2 hard levels

Upgrades

Coins you earn buy permanent upgrades for Block Jam:

  • ⏱️ Extra Time — +10 s on every level
  • 🔨 Hammer Kit — +1 hammer at the start of a run
  • 🪙 Gold Bricks — +15% coins from each run

Good to know

  • Free and instant: runs in your browser on phone, tablet or desktop — nothing to install.
  • Session length: about 2–5 min per round, perfect for a short break.
  • Progress saves automatically in this browser: best scores, missions and favorites.
