Merge Town

Merge tents into castles and skyscrapers before the town fills up.

▶ Play Merge Town now All games

How to play Merge Town

  1. New buildings drop onto the board. Drag a building onto an identical one to merge it into the next tier: tent, hut, cottage, house, villa, tower, castle and beyond.
  2. Drag onto an empty plot to move. If a building drops when every plot is taken, the town is full and the run ends.
  3. Cranes upgrade any building one tier, bulldozers clear a plot. Storms shuffle a few buildings around. Quick merges build a combo.
  4. Big merges grow your town level: drops speed up and new seasons arrive. High tiers pay coins, which buy calmer skies, more cranes and bonus coins.

Missions to chase

Every run counts toward missions that pay out XP. Clear a tier to unlock the next one:

  • Build a Villa
  • Make 50 merges
  • Reach town level 3
  • Build a Castle
  • Make 500 merges
  • Bulldoze 30 buildings

Upgrades

Coins you earn buy permanent upgrades for Merge Town:

  • 🌤️ Calm Skies — Buildings drop 6% slower
  • 🏗️ Foreman — Start with a crane; cranes come more often
  • 🪙 Mayor — +15% coins from each run

Good to know

  • Free and instant: runs in your browser on phone, tablet or desktop — nothing to install.
  • Session length: about 3–10 min per round, perfect for a short break.
  • Progress saves automatically in this browser: best scores, missions and favorites.
