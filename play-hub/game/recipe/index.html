Recipe Rush

Remember each order, then build it exactly right.

▶ Play Recipe Rush now All games

How to play Recipe Rush

  1. A customer shows their order ticket for a moment — memorise every ingredient and its order, then it flips over.
  2. Tap the ingredient trays in the same order to build the dish. Fast, perfect orders earn bigger tips.
  3. A wrong ingredient or an empty patience bar costs a heart. Watch for NO requests, x2 helpings and combo orders.
  4. Tap the ticket button to peek once more. Drinks, hot dogs and sundaes unlock as you go — every 5th level is Rush Hour.

Missions to chase

Every run counts toward missions that pay out XP. Clear a tier to unlock the next one:

  • Reach level 4
  • Serve 15 orders
  • Serve 5 perfect orders in a run
  • Reach level 10
  • Survive 3 rush hours
  • Serve 150 orders

Upgrades

Coins you earn buy permanent upgrades for Recipe Rush:

  • 🧾 Sharp Memory — +15% time to read each ticket
  • 👀 Order Peek — Start each run with +1 ticket peek
  • 🪙 Big Tipper — +15% coins from each run

Good to know

  • Free and instant: runs in your browser on phone, tablet or desktop — nothing to install.
  • Session length: about 2–5 min per round, perfect for a short break.
  • Progress saves automatically in this browser: best scores, missions and favorites.
