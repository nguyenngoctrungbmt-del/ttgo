# TTGO Landing Page

Trang landing page tĩnh dùng để quảng cáo các tựa game của **AVTFINITY** trên Google Play.

## Chạy/host

- Nếu bạn host tĩnh: chỉ cần upload `index.html` (khuyến nghị giữ cùng cấu trúc file).
- Nếu bạn muốn preview nhanh cục bộ: mở trực tiếp `index.html` bằng trình duyệt.

## Branch `TTGO`

Thư mục hiện tại chưa phải git repo. Khi bạn bật git, hãy tạo branch theo tên `TTGO`.
